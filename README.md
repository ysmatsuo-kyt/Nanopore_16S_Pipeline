# Bioinformatics Pipeline for Full-length 16S rRNA Gene Analysis Using Nanopore Sequencing

## Overview

This repository contains the scripts used for Nanopore-based full-length 16S rRNA gene sequencing and microbiome analysis. The workflow consists of three main steps:

1.  Sequence quality control: Quality assessment of raw sequencing data.
2.  Pre-processing and taxonomic classification: Sequence filtering and processing, followed by bacterial taxonomic identification using EPI2ME wf-16s.
3.  Microbiome analysis: Analysis of taxonomic composition, microbial diversity, and differential abundance.
