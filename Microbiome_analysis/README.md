# Microbiome analysis workflow

`microbiome_analysis.qmd`

## Overview

Downstream microbiome analyses are performed in `R`. The workflow includes the following analyses:

-   **Microbial composition profiling:** Characterization of microbial taxonomic composition.
-   **Rarefaction and sequencing depth assessment:** Evaluation of sequencing depth and read coverage.
-   **Alpha diversity analysis:** Assessment of observed richness and Shannon diversity.
-   **Beta diversity analysis:** Calculation of Bray–Curtis dissimilarity, Jaccard distance, and Jensen–Shannon divergence, followed by principal coordinates analysis (PCoA) for ordination and PERMANOVA for statistical testing.
-   **Differential abundance analysis:** Identification of differentially abundant taxa using ANCOM-BC2 and ALDEx2.

## Software environment

-   R (4.5.2)
-   Quarto (1.9.36)

## Input files

-   `wf-16s-counts-species.csv`
    -   Species-level abundance table generated by the upstream taxonomic classification workflow.
-   `metadata.csv`
    -   Sample metadata used for sample grouping and statistical analyses.

## Running the workflow

Place `microbiome_analysis.qmd` and both input files in the same working directory. Run the following command in the terminal:

``` bash
quarto render microbiome_analysis.qmd
```

Alternatively, open `microbiome_analysis.qmd` in `RStudio` and click the `Render` button to execute the workflow.
