# Example dataset for microbiome analysis workflow

## Overview

This dataset contains microbiome data derived from fecal samples of medaka fish (_Oryzias latipes_) reared under contrasting environmental conditions. It provides example input files and a Quarto-based analysis workflow for reproducing downstream microbiome analyses.

## Files

-   `metadata.csv`
    -   Sample metadata used for group assignment and statistical analyses.
-   `wf-16s-counts-species.csv`
    -   Species-level abundance table generated by the EPI2ME wf-16s.
-   `medaka_microbiome_analysis.qmd`
    -   Quarto document containing all R code used for microbiome analyses.
-   `outputs/`
    -   Example output files generated by the workflow.

## Software environment

-   R (4.5.2)
-   Quarto (1.9.36)

## Required R packages

The workflow was developed and tested using the following package versions:

-   tidyverse 2.0.0

-   vegan 2.7-3
-   philentropy 0.10.0
-   phyloseq 1.54.2

-   ggbeeswarm 0.7.3
-   ANCOMBC 2.12.0
-   ALDEx2 1.42.0
-   microbiome 1.32.0

## Running the workflow

Place `medaka_microbiome_analysis.qmd` and input files (`wf-16s-counts-species.csv` and `metadata.csv`) in the same working directory. Run the following command in the terminal:

```{bash}
quarto render medaka_microbiome_analysis.qmd
```

Alternatively, open `medaka_microbiome_analysis.qmd` in `RStudio` and click the `Render` button to execute the workflow.
